# Visualization

Choose a viewer for the downloaded *Berlin Waters* bag:

| Viewer | What it does | Guide |
| --- | --- | --- |
| Rerun | Opens a bag or extracted files without ROS 2 | [Rerun](rerun/README.md) |
| RViz | Displays ROS 2 bag playback with the supplied sensor layout and transforms | [ROS 2 and RViz](ros2/README.md) |
| Foxglove | Displays ROS 2 bag playback through a local bridge and supplied layout | [Foxglove](foxglove/README.md) |

Follow the linked guide for installation and commands. The [main Tools section](../../README.md#tools)
covers the common setup.
